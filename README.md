## More Project Details
### Biomechanical Posture App & Neural Network
These two projects were made as a part of my work as an Undergraduate Research Assistant for a biomechanical lab at Queen's. I:
*	Designed, developed, and deployed an iOS application that connects via Bluetooth Low Energy (BLE) with a wearable bio-feedback system to deliver real-time spine loading information regarding user posture and vibrotactile feedback alerts
*	Built and maintained server infrastructure to stream, process, and store real-time load data into a database, enabling future analysis and historical data retrieval for tracking with long-term subjects 
*	Developed and trained a deep learning model to accurately estimate mechanical loads in the spine based on single-axis IMU sensor streams, optimizing and integrating the model into the mobile app for real-time feedback
*	Engineered synthetic data generation pipelines to simulate varied, continuous posture IMU signals, mimicking datasets collected on real subjects, and mitigating dataset scarcity and improving model accuracy and convergence
*	Collaborated and tested with lab members to ensure seamless integration of the app with the wearable sensor hardware, ensuring functionality and reliability in real-world clinical settings
